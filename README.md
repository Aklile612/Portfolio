# Aklile Ansa Portfolio

Personal portfolio inspired by [victoreke.com](https://victoreke.com), customized with my experience, projects, and résumé.

## Stack

- Next.js
- Tailwind CSS
- Framer Motion
- next-themes
- react-github-calendar

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` and set your GitHub username/year if needed.

## Content

Update personal content in:

- `app/data/profile.ts`
- `app/data/jobs.ts`
- `app/data/projects.ts`
- `app/data/social.ts`
- `app/data/usage.ts`
- `app/data/site.ts`

Résumé PDF: `public/Aklile_Ansa.pdf`
